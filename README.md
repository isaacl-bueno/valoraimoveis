# Valora Imóveis

Site Next.js da Valora Imóveis, convertido do protótipo HTML com o mesmo layout e a cor de marca em azul (`#0B4F8A`).

## Páginas

- `/` — Home
- `/imoveis` — Catálogo
- `/imoveis/[slug]` — Detalhes do imóvel
- `/sobre` — Sobre
- `/contato` — Contato
- `/login` — Acesso administrativo
- `/admin/imoveis` — Gestão de imóveis
- `/admin/imoveis/form` — Cadastro/edição
- `/admin/usuarios` — Usuários

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
